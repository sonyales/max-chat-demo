# MAX Chat — тестовое задание React

Тестовое задание на позицию фронтенд-разработчика React: пользовательский интерфейс для обмена текстовыми сообщениями с простым набором функций и оформлением в стиле веб-версии MAX.

[Открыть приложение](https://sonyales.github.io/max-chat-demo/) · [Инструкция запуска](#локальный-запуск)

## О проекте

Приложение реализует сценарий мессенджера: вход, создание чата по номеру телефона получателя, отправка текстового сообщения и отображение ответа в переписке.

Взаимодействие с GREEN-API имитируется локально. Реальные аккаунты, токены и подключение к MAX или Telegram не требуются. Ответы собеседника формируются автоматически. Данные хранятся в памяти вкладки и очищаются при выходе или перезагрузке страницы.

## Возможности

- Форма входа с полями «Телефон» и «Пароль» и заполнением тестовых данных.
- Создание личного чата по номеру телефона с проверкой формата.
- Список чатов и переключение между получателями без смешивания переписки.
- Отправка и получение только текстовых сообщений.
- Отображение входящих и исходящих сообщений, времени и состояния отправки.
- Ограничение длины сообщения до 4000 символов и запрет пустых сообщений.
- Отправка по Enter; перенос строки по Shift + Enter.
- Отдельный черновик для каждого чата.
- Адаптивный интерфейс для компьютера и телефона.

## Имитация GREEN-API

Локальный адаптер `MockGreenApi` воспроизводит основной контракт методов из задания:

- `sendMessage({ chatId, message })` принимает текст и идентификатор получателя, возвращает `idMessage`.
- `receiveNotification()` возвращает входящее уведомление из очереди.
- `deleteNotification(receiptId)` подтверждает обработку и удаляет уведомление.

Уведомления обрабатываются по порядку и остаются в очереди до подтверждения. Повторно полученное сообщение не дублируется в интерфейсе. При выходе опрос очереди и ожидающие ответы прекращаются.

Внутри адаптера сохранены параметры `idInstance` и `apiTokenInstance`; в интерфейсе они представлены как «Телефон» и «Пароль». Это тестовая форма, а не реальная авторизация по номеру телефона. Приложение не выполняет HTTP-запросы к GREEN-API.

## Стек

React 19, JavaScript, CSS, Vite 7. Тесты — встроенный модуль Node.js `node:test`. Публикация — GitHub Pages через GitHub Actions.

## Локальный запуск

Требуется **Node.js 22.12 или новее** и **npm**.

1. Скачайте исходники репозитория и откройте папку проекта в терминале.
2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите приложение:

   ```bash
   npm run dev
   ```

4. Откройте адрес, указанный в терминале, обычно `http://127.0.0.1:5173/`.

Альтернатива с pnpm: `pnpm install --frozen-lockfile`, затем `pnpm run dev`.

## Как проверить

1. Нажмите «Заполнить демо-данные» и «Войти в чат».
2. Создайте новый чат с вымышленным номером, например `+7 999 123-45-67`.
3. Напишите и отправьте сообщение.
4. Через 1–2 секунды в переписке появится автоматический ответ.
5. Создайте второй чат и проверьте переключение между переписками.

Для ручного входа можно использовать телефон `7100000001` и пароль `demo-token`.

## Проверка и сборка

```bash
npm test
npm run build
npm run preview
```

Тесты проверяют валидацию ввода, маршрутизацию ответов по получателям, порядок уведомлений, подтверждение их обработки и завершение сеанса. Production-сборка создаётся в папке `dist/`.
